# Educational Website & Review System

A responsive educational website for presenting courses, collecting user feedback, and managing reviews through an admin approval system.

## Features

- Course and summer camp presentation pages
- Lead collection via contact forms
- Review submission system with moderation
- Admin dashboard for approving reviews
- Firebase integration for data storage
- Interactive UI with popups and animations

## Tech Stack

- HTML, SCSS, JavaScript
- PHP
- Firebase (Auth, Firestore, Storage)

## Notes

Built as a real-world educational platform template used for client presentation and course promotion.
